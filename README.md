# そのCO₂のつけは、誰が払う？ ― AR体験（試作版 v0.9）

チームのデモを土台に、作業指示書 第6章の S0〜S8 を当てた実装版です。

## このフォルダの中身
- `index.html` … アプリ本体（デモ＋AR2場面＋体験3-2＋保存先の置き換え＋実証用の切り替え＋審査員用の近道）
- `data/data.json` … 数値と出典（`tools/export_data.py` で作る）
- `models/` … ARのモデル95個（立方体：1日分・1年分・人生分10〜99歳、浸水：0.5m・1.0m・3.0m）
- `tools/` … `export_data.py`（data.json作成）、`make_models.py`（モデル作成）、`hotdays.py`（気象庁の猛暑日データ）、`patch_demo.py`（デモ→index.html の変換）
- `gas/Code.gs` … 匿名の保存と集計（Google Apps Script）
- `demo_original.html` … 変換前のデモ（比較用）

## 公開のしかた（GitHub Pages）
1. GitHubで公開リポジトリ `co2-ar` を作り、このフォルダの中身をすべてアップロードする。
2. Settings → Pages → main ブランチを公開。`https://<ユーザー名>.github.io/co2-ar/` で開ける。
3. 審査員用URL：`https://<ユーザー名>.github.io/co2-ar/?start=ar`

## URLの切り替え
- `?start=ar` … 体験1のARの場所から始まる（審査員用）
- `?g=A` / `?g=B` … 実証の群を保存データに記録
- `?mode=text` … 3DとARを隠す（実証のB群用）

## 数値を直すとき
`python tools/export_data.py owid-co2-data.csv` → `cd models && python ../tools/make_models.py ../data/data.json`

## まだチームがやること
1. **保存先**：`gas/Code.gs` をデプロイし、発行URLを `index.html` の `const API=''` に入れる（空のままだと保存しない）。
2. **企業の商品選択の事前・事後の設問**と**理解度クイズ3問**：内閣府調査の設問文を一字一句確認してから、「はじめに」と「体験のあと」に追加する（保存列 cpre・cpost・quiz は用意済み）。
3. **体験3-2の地域**：いまは近畿＝大阪、関東甲信＝東京、東海＝名古屋、九州北部＝福岡。ほかの地方は大阪の値を表示する。札幌・仙台・新潟・広島・鹿児島のCSV（気象庁「大都市における猛暑日日数の長期変化傾向」）を `tools/hotdays.py` に足せば広げられる。
4. **B群用の静止画**：`?mode=text` では3Dが隠れるだけなので、体験1・4の3Dを撮った画像を足す。
5. **デモに書かれた数値の出典照合**（熱帯夜・大雨・海面・西日本豪雨・熱中症など）を数値台帳で行う。
6. **実機テスト**（作業指示書 第6章の端末テスト表）。PC上の自動テストでは動作を確認済みだが、実機のARは未確認。
